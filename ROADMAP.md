# Roadmap

## Phase 1: design and registration

- review the study concept with supervisors;
- freeze the RCT Bench version and eligibility criteria;
- complete philosophical source checking;
- write the ADEMP simulation protocol;
- lock estimators, thresholds, estimands and fairness analyses;
- tag and register protocol version 1.0.

## Phase 2: implementation

- implement reproducible data acquisition and manifest checks;
- build trial-blind eligibility screening;
- implement the four checks and comparators;
- implement known-truth and doubly robust evaluation;
- add unit, integration and invariant tests;
- implement resumable, fingerprinted simulation batches.

## Phase 3: validation

- run code-only integrity tests after protocol lock;
- run controlled simulations;
- run RCT-shaped semi-synthetic validation;
- run real-outcome multitrial evaluation;
- conduct raw and evidence-standardised fairness audits;
- report all failures and prespecified scenarios.

## Phase 4: manuscript

- write Methods before unblinding aggregate results;
- generate tables and figures directly from frozen outputs;
- draft Results and Discussion, including negative findings;
- complete reporting checklists and archive a reproducible release.
