# Results

Only aggregate, disclosure-safe, reproducible outputs belong here. Exploratory,
confirmatory and sensitivity outputs must use separate subdirectories.

Pre-lock proof-of-concept diagnostics are written to `results/poc/`, which is
ignored by Git. They contain software-invariant statuses and computational
fingerprints, not scientific effect estimates. A reviewed feasibility summary
may be committed later as a separate aggregate document.

Unblinded Stage C development outputs are written to
`results/development/stage-c/`, which is also ignored by Git. Raw run reports
must be retained locally or in an approved research archive. Only a reviewed,
clearly labelled exploratory summary may later be committed. Independent
validation outputs must use a distinct directory and may not overwrite or be
combined with development results.
