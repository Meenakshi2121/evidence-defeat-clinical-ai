# Decisions required before protocol lock

1. Confirm the primary four-check gate: data adequacy, support, model
   multiplicity and decision uncertainty.
2. Define the clinical indifference/materiality margin and its sensitivity
   values.
3. Freeze the RCT Bench version by release or commit hash.
4. Finalise trial eligibility, outcome-missingness threshold and binary-contrast
   adjudication.
5. Choose the exact causal estimators and hyperparameters.
6. Define the default policy without using held-out outcomes.
7. Fix the simulation and semi-synthetic scenario grid.
8. Set Monte Carlo precision targets and derive replicate counts.
9. Define protected-group availability and minimum cell-size reporting rules.
10. Decide whether a weighted fairness composite is omitted or retained only as
    a labelled sensitivity analysis.
11. Confirm primary and secondary journal targets.
12. Register the protocol and tag the repository before outcome analysis.
